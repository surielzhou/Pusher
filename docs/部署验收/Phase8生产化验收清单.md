## 1. 配置与环境变量

| 配置项 | 必填条件 | 验收要求 |
| --- | --- | --- |
| `APP_BASE_URL` | 生产环境必填 | 指向正式访问地址，本地验收可使用 `http://127.0.0.1:3000`。 |
| `AI_TEXT_PROVIDER` | 生产环境必填 | 标明文本生成 provider，例如 `openai`、`custom` 或受控 fake provider。 |
| `AI_TEXT_API_KEY` | `AI_TEXT_PROVIDER=openai/custom` 必填 | 密钥只通过部署平台注入，不写入仓库、文档或日志。 |
| `AI_IMAGE_PROVIDER` | 启用 AI 图片生成时必填 | 标明图片生成 provider。 |
| `AI_IMAGE_API_KEY` | `AI_IMAGE_PROVIDER=openai/custom` 必填 | 密钥只通过部署平台注入。 |
| `WECHAT_DRAFT_ENABLED` | 启用公众号草稿创建时必填 | `true` 时必须完成微信账号配置。 |
| `WECHAT_APP_ID` | `WECHAT_DRAFT_ENABLED=true` 必填 | 指向目标公众号应用。 |
| `WECHAT_APP_SECRET` | `WECHAT_DRAFT_ENABLED=true` 必填 | 通过部署平台注入，不记录明文。 |
| `PERSISTENCE_DRIVER` | 生产环境必填 | 生产环境不得使用 `memory`；可用 `file`、`database`、`sqlite` 或 `postgres`。 |
| `DATABASE_URL` | 数据库持久化必填 | 数据库连接串可访问，权限满足读写和迁移。 |
| `FILE_STORAGE_ROOT` | 文件持久化或上传图片必填 | 指向稳定挂载目录，并纳入备份策略。 |
| `LOG_LEVEL` | 否 | 建议生产环境使用 `info`，排障时临时切到 `debug`。 |

验收勾选：

- [ ] `/audit` 页面环境校验没有阻塞项。
- [ ] AI 文本生成、AI 图片生成、微信草稿、持久化配置均已明确启用或明确禁用。
- [ ] 密钥未提交到仓库、镜像层、验收记录或前端页面。
- [ ] 生产环境未使用内存持久化。

## 5. 回滚方案

回滚触发条件：

- `/workbench` 或 `/audit` 无法访问。
- 环境校验出现生产阻塞项。
- 主链路无法完成生成、编辑、Review、发布准备。
- 审计时间线缺少关键动作或暴露敏感信息。
- 持久化写入失败，且无法在维护窗口内修复。

回滚步骤：

1. 停止当前版本应用。
2. 切回上一稳定版本镜像或部署包。
3. 如已执行数据迁移，按迁移工具说明回滚；无法回滚时恢复部署前备份。
4. 重新注入上一稳定版本所需环境变量。
5. 启动上一稳定版本。
6. 访问 `/workbench` 和 `/audit`，执行主流程冒烟验收。
7. 记录回滚原因、影响范围、数据恢复状态和后续修复负责人。

回滚验收勾选：

- [ ] 上一稳定版本启动成功。
- [ ] 工作台和审计页面可访问。
- [ ] 数据备份或恢复结果已确认。
- [ ] 回滚过程没有新增密钥泄露或数据丢失。

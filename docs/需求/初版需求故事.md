# 初版需求故事

## 背景

当前项目的初衷是服务公众号内容分享，主要面向科技互联网、金融、文学三个内容方向。项目需要围绕这些方向进行内容生成，并支持将文章推送到公众号发布链路中。

## 核心需求故事

作为内容创作者或运营者，我希望系统能够根据选定主题生成适合公众号分享的图文文章，覆盖科技互联网、金融、文学等内容方向，并在文章正式发表或推送前保留人工 review 介入点，以便我检查内容质量、表达风格、图文匹配度与发布风险后再决定是否发布。

## 目标用户

- 内容创作者
- 公众号运营者
- 需要稳定产出行业内容、观点文章或文学分享内容的个人或团队

## 内容方向

- 科技互联网：行业趋势、产品观察、技术热点、公司动态、AI 与数字化相关内容。
- 金融：市场观察、商业分析、投资常识、宏观经济或公司财务相关内容。
- 文学：书评、散文、观点随笔、作家作品解读、文学主题分享。

## 初版功能范围

- 支持按主题或方向生成公众号文章。
- 文章格式需要同时包含文字内容和图片内容。
- 支持生成适合公众号阅读场景的标题、摘要、正文结构和配图建议。
- 支持文章进入发布前 review 流程，由人工确认、修改、退回或批准。
- 支持将审核通过后的文章进入推送或发布准备流程。

## 发布前 Review 要求

- 文章生成后默认进入待 review 状态。
- review 人可以查看完整图文内容。
- review 人可以介入修改标题、摘要、正文和图片。
- review 人可以标记审核结果：通过、退回修改、暂不发布。
- 未通过 review 的文章不得进入正式发布或推送环节。

## 初版验收标准

- 给定一个主题或内容方向后，系统能产出一篇结构完整的公众号文章草稿。
- 每篇文章必须包含文字内容和至少一项图片内容或配图方案。
- 文章在发布前必须经过人工 review 状态。
- review 结果能够影响文章后续状态，未通过 review 的文章不能发布。
- 内容方向至少能覆盖科技互联网、金融、文学三类。

## 待进一步澄清

- 图片来源：使用 AI 生成、素材库选择、外部图片搜索，还是由人工上传。
- 推送方式：仅生成公众号可复制内容，还是直接对接公众号发布接口。
- review 角色：是否只有当前使用者本人，还是需要多人审核协作。
- 内容合规：金融类内容是否需要额外的风险提示、免责声明或敏感词检查。
- 文章保存：是否需要历史版本、审核记录和发布记录。

# 用户动线拆分

## 文档目的

本文基于 `docs/需求/初版需求故事.md`，将公众号图文内容生成与推送场景拆分为可设计、可开发、可测试的用户动线。

初版重点围绕以下闭环：

- 用户发起选题。
- 系统生成图文文章草稿。
- 用户介入编辑和 review。
- 审核通过后进入发布或推送准备。

## 角色拆分

### 内容创作者

负责发起文章生成任务，输入主题、内容方向和生成要求，并对生成结果进行编辑。

### Review 人

负责在发布前检查文章内容、配图、风险和最终呈现效果，并决定是否允许进入发布环节。

初版可以默认内容创作者和 Review 人为同一个用户，但动线需要保留 review 状态，方便后续扩展多人审核。

### 发布执行者

负责将审核通过的文章推送到公众号发布链路。初版可以先支持复制发布内容或生成发布准备稿，后续再对接公众号接口。

### 系统

负责生成文章草稿、提供配图方案、维护文章状态，并根据 review 结果控制后续流转。

## 主用户动线

### 1. 进入创作入口

用户进入系统后，选择创建一篇新的公众号文章。

关键动作：

- 点击新建文章。
- 进入选题与生成配置页面。

系统结果：

- 创建一条文章任务记录。
- 初始状态为 `草稿中`。

### 2. 选择内容方向

用户选择文章所属方向。

可选方向：

- 科技互联网
- 金融
- 文学

关键动作：

- 选择内容方向。
- 输入文章主题或关键词。
- 可选输入目标读者、文章风格、篇幅要求、参考素材。

系统结果：

- 记录生成参数。
- 根据内容方向选择对应生成策略。

### 3. 生成图文文章草稿

用户确认生成后，系统生成文章初稿。

系统需要生成：

- 标题
- 摘要
- 正文结构
- 正文内容
- 配图建议或图片内容
- 可选的发布提示或风险提示

系统结果：

- 文章状态进入 `待编辑`。
- 如果生成失败，文章状态进入 `生成失败`，允许用户重试。

### 4. 编辑和补充图文内容

用户查看系统生成的图文文章草稿，并进行必要调整。

关键动作：

- 修改标题。
- 修改摘要。
- 修改正文。
- 替换、上传或重新生成图片。
- 调整图片与正文段落的对应关系。

系统结果：

- 保存文章编辑结果。
- 文章仍处于 `待编辑`。

### 5. 提交 Review

用户完成编辑后，将文章提交到发布前 review。

关键动作：

- 点击提交 review。
- 系统校验文章是否满足最低发布条件。

最低发布条件：

- 有标题。
- 有正文。
- 有至少一项图片内容或配图方案。
- 有明确内容方向。

系统结果：

- 校验通过后，状态进入 `待Review`。
- 校验不通过时，提示用户补齐缺失内容。

### 6. Review 图文文章

Review 人查看完整文章内容和发布预览。

Review 重点：

- 标题是否准确。
- 内容是否符合选题方向。
- 正文是否可读、完整、有观点。
- 图片是否与内容匹配。
- 金融类内容是否存在明显风险表达。
- 是否适合公众号发布场景。

Review 结果：

- 通过
- 退回修改
- 暂不发布

### 7. Review 通过后进入发布准备

Review 通过后，文章进入发布准备流程。

关键动作：

- 查看最终发布预览。
- 复制公众号排版内容，或进入公众号推送接口准备。
- 确认发布信息。

系统结果：

- Review 通过时记录审核状态为 `已通过`。
- 状态进入 `待发布`。
- 发布完成后进入 `已发布`。
- 发布失败时进入 `发布失败`。

## 分支动线

### 分支 A：生成结果不满意

触发场景：

- 内容不符合主题。
- 文章风格不合适。
- 篇幅过长或过短。
- 观点深度不足。

用户动作：

- 修改生成要求。
- 重新生成全文。
- 只重新生成标题、摘要、正文段落或配图。

系统结果：

- 保留当前版本。
- 生成新版本供用户选择或继续编辑。

### 分支 B：图片不合适

触发场景：

- 图片与内容不匹配。
- 图片风格不适合公众号。
- 图片来源或版权不明确。

用户动作：

- 重新生成图片。
- 替换为素材库图片。
- 人工上传图片。
- 暂时保留配图建议。

系统结果：

- 更新文章图片内容。
- 保留图片来源或生成方式记录。

### 分支 C：Review 退回修改

触发场景：

- 内容质量不达标。
- 表达有风险。
- 图片不匹配。
- 不适合当前发布节奏。

Review 人动作：

- 标记为退回修改。
- 填写退回原因。

创作者动作：

- 根据退回原因修改文章。
- 再次提交 review。

系统结果：

- 状态从 `待Review` 进入 `Review退回`。
- 修改后可重新进入 `待Review`。

### 分支 D：暂不发布

触发场景：

- 选题暂缓。
- 内容不再适合发布。
- 需要等待外部信息确认。

Review 人动作：

- 标记为暂不发布。
- 可选填写原因。

系统结果：

- 状态进入 `暂不发布`。
- 文章不允许进入发布环节。
- 后续可以重新编辑并再次提交 review。

### 分支 E：发布失败

触发场景：

- 公众号接口失败。
- 内容格式不符合发布要求。
- 图片上传失败。
- 人工发布时发现排版问题。

用户动作：

- 查看失败原因。
- 修改文章或图片。
- 重新生成发布内容。
- 再次尝试发布。

系统结果：

- 状态进入 `发布失败`。
- 修正后可重新进入 `待发布`。

## 状态流转

```text
草稿中
  -> 待编辑
  -> 待Review
  -> 已通过
  -> 待发布
  -> 已发布
```

异常和分支状态：

```text
草稿中 -> 生成失败 -> 草稿中
待Review -> Review退回 -> 待编辑 -> 待Review
待Review -> 暂不发布
待发布 -> 发布失败 -> 待发布
```

## 页面与模块拆分

### 创作入口

提供新建文章入口，展示文章方向、最近草稿和当前待处理文章。

### 生成配置页

承载内容方向选择、主题输入、生成要求配置和参考素材输入。

### 图文编辑页

承载文章标题、摘要、正文、图片、配图说明和图文预览编辑能力。

### Review 页

承载发布前检查、审核意见、审核结果操作和文章最终预览。

### 发布准备页

承载公众号排版预览、复制发布内容、发布接口准备或发布结果展示。

### 历史文章页

展示不同状态的文章记录，支持按方向、状态和时间筛选。

## MVP 建议范围

初版优先实现以下动线：

- 新建文章。
- 选择科技互联网、金融、文学三类方向。
- 输入主题并生成图文草稿。
- 支持人工编辑标题、摘要、正文和图片。
- 支持提交 review。
- 支持 review 通过、退回修改、暂不发布。
- 支持审核通过后进入发布准备。

暂不强依赖以下能力：

- 多人协同审核。
- 自动对接公众号发布接口。
- 完整素材库。
- 完整历史版本对比。

## 待确认问题

- 初版发布方式是复制到公众号后台，还是直接对接公众号接口。
- 图片初版来源优先采用 AI 生成、人工上传，还是只给配图建议。
- Review 是否只需要单人审核，还是需要多人角色和权限。
- 金融内容是否需要强制展示免责声明或合规检查结果。
- 是否需要保存每次生成和退回修改的历史版本。

## 设计范围

### MVP 范围

- 单用户完成公众号图文文章的创建、生成、编辑、review 和发布准备。
- 内容方向支持科技互联网、金融、文学。
- 文章至少包含标题、摘要、正文和一项图片内容或配图方案。
- 发布前必须经过 review。
- 发布准备优先支持人工复制到公众号后台。
- 图片初版支持配图方案和图片记录，真实 AI 图片生成、素材库和外部图片搜索作为扩展。

### 非 MVP 范围

- 多用户账号体系和权限分配。
- 多人协同 review。
- 公众号接口自动发布。
- 完整素材库。
- 多版本差异对比。
- 自动合规拦截闭环。

## 设计假设

- 初版使用者同时承担内容创作者、Review 人和发布执行者角色。
- Review 页不直接编辑文章内容；Review 人如需修改，先退回修改，再进入图文编辑页完成修改。
- 文章正文初版以 Markdown 或结构化文本块保存，发布准备模块负责导出公众号可复制内容。
- 文章内容一旦在 review 通过后再次修改，需要重新进入 review。
- 金融类内容初版只做风险提示和人工检查，不做自动拦截。

## 领域模型

### 枚举定义

#### ContentCategory

| 枚举值 | 展示名 | 说明 |
| --- | --- | --- |
| `tech_internet` | 科技互联网 | 行业趋势、产品观察、技术热点、公司动态、AI 与数字化内容 |
| `finance` | 金融 | 市场观察、商业分析、投资常识、宏观经济或公司财务内容 |
| `literature` | 文学 | 书评、散文、观点随笔、作家作品解读、文学主题分享 |

#### ArticleStatus

| 枚举值 | 展示名 | 说明 |
| --- | --- | --- |
| `drafting` | 草稿中 | 已创建文章任务，正在配置或等待生成 |
| `generation_failed` | 生成失败 | 文本生成失败或关键生成结果缺失 |
| `editing` | 待编辑 | 已生成草稿，等待人工编辑和补充 |
| `pending_review` | 待Review | 已提交 review，等待审核决策 |
| `review_rejected` | Review退回 | 审核退回，需修改后重新提交 |
| `approved` | 已通过 | review 已通过，可进入发布准备 |
| `not_publish` | 暂不发布 | review 决定暂不发布 |
| `pending_publish` | 待发布 | 已生成发布准备内容，等待人工发布或后续接口发布 |
| `publish_failed` | 发布失败 | 发布准备或发布动作失败，需修正 |
| `published` | 已发布 | 已完成发布记录 |

#### ImageType

| 枚举值 | 展示名 | 说明 |
| --- | --- | --- |
| `suggestion` | 配图建议 | 仅有描述或提示词，没有真实图片 |
| `generated` | AI 生成图片 | 后续接入 AI 图片生成后使用 |
| `uploaded` | 人工上传图片 | 用户上传图片 |
| `material` | 素材库图片 | 后续素材库能力使用 |
| `external` | 外部图片 | 后续外部图片搜索或引用使用 |

#### ReviewResult

| 枚举值 | 展示名 | 说明 |
| --- | --- | --- |
| `approved` | 通过 | 允许进入发布准备 |
| `rejected` | 退回修改 | 退回编辑链路 |
| `not_publish` | 暂不发布 | 当前文章不进入发布链路 |

#### PublishStatus

| 枚举值 | 展示名 | 说明 |
| --- | --- | --- |
| `prepared` | 已准备 | 已生成可发布内容 |
| `published` | 已发布 | 人工标记或接口确认已发布 |
| `failed` | 失败 | 发布准备或发布动作失败 |

## 数据结构设计

### Article

表示一篇公众号文章的主记录。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 文章 ID |
| `title` | string | 否 | 标题，提交 review 前必填 |
| `summary` | string | 否 | 摘要 |
| `body` | string | 否 | 正文，提交 review 前必填 |
| `category` | ContentCategory | 是 | 内容方向 |
| `status` | ArticleStatus | 是 | 当前文章状态 |
| `generationConfig` | object | 是 | 生成配置 |
| `riskNote` | string | 否 | 风险提示，金融内容优先生成 |
| `contentVersion` | number | 是 | 内容版本，标题、摘要、正文或图片变化时递增 |
| `reviewedVersion` | number | 否 | 最近一次通过 review 的内容版本 |
| `publishedVersion` | number | 否 | 最近一次发布的内容版本 |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 是 | 更新时间 |

设计规则：

- `contentVersion` 初始为 `1`。
- 用户编辑标题、摘要、正文或图片时递增 `contentVersion`。
- Review 通过时将 `reviewedVersion` 设为当前 `contentVersion`。
- 发布准备和发布动作必须基于 `reviewedVersion == contentVersion`。

### GenerationConfig

表示文章生成输入。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `category` | ContentCategory | 是 | 内容方向 |
| `topic` | string | 是 | 主题或关键词 |
| `audience` | string | 否 | 目标读者 |
| `style` | string | 否 | 文章风格 |
| `length` | string | 否 | 篇幅要求 |
| `references` | string[] | 否 | 参考素材或参考点 |
| `requireRiskNote` | boolean | 是 | 金融方向默认为 true |

### ArticleImage

表示文章图片或配图方案。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 图片记录 ID |
| `articleId` | string | 是 | 关联文章 ID |
| `type` | ImageType | 是 | 图片类型 |
| `url` | string | 否 | 图片地址，配图建议时可为空 |
| `description` | string | 是 | 图片说明、配图建议或生成提示 |
| `source` | string | 否 | 图片来源 |
| `position` | string | 否 | 建议插入位置，如摘要后、段落编号后 |
| `altText` | string | 否 | 图片替代文本 |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 是 | 更新时间 |

设计规则：

- 提交 review 前，至少存在一条 `ArticleImage`。
- 当 `type = suggestion` 时，`description` 必填，`url` 可为空。
- 当 `type != suggestion` 时，`url` 或可访问文件引用必填。

### ReviewRecord

表示一次 review 操作记录。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 审核记录 ID |
| `articleId` | string | 是 | 关联文章 ID |
| `articleVersion` | number | 是 | 审核时的内容版本 |
| `result` | ReviewResult | 是 | 审核结果 |
| `comment` | string | 否 | 审核意见 |
| `reviewChecklist` | object | 否 | 审核检查项结果 |
| `reviewedAt` | datetime | 是 | 审核时间 |

设计规则：

- `rejected` 必须填写 `comment`。
- `not_publish` 建议填写 `comment`。
- `approved` 后将文章状态更新为 `approved`，并同步 `reviewedVersion`。

### PublishRecord

表示发布准备或发布结果。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 发布记录 ID |
| `articleId` | string | 是 | 关联文章 ID |
| `articleVersion` | number | 是 | 发布所用内容版本 |
| `channel` | string | 是 | 初版为 `wechat_manual` |
| `status` | PublishStatus | 是 | 发布状态 |
| `exportContent` | string | 否 | 可复制发布内容 |
| `imageChecklist` | object[] | 否 | 图片清单 |
| `errorMessage` | string | 否 | 失败原因 |
| `publishedAt` | datetime | 否 | 发布时间 |
| `createdAt` | datetime | 是 | 创建时间 |

设计规则：

- 创建发布准备记录前，文章必须处于 `approved` 或 `pending_publish`。
- 创建发布准备记录前，必须满足 `reviewedVersion == contentVersion`。
- 如果用户修改了正文或图片，原发布准备记录失效，文章回到 `editing`。

### ArticleStatusEvent

表示文章状态变化记录。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 状态事件 ID |
| `articleId` | string | 是 | 关联文章 ID |
| `fromStatus` | ArticleStatus | 否 | 原状态，创建时为空 |
| `toStatus` | ArticleStatus | 是 | 新状态 |
| `reason` | string | 否 | 状态变化原因 |
| `createdAt` | datetime | 是 | 记录时间 |

## 状态流转详细规则

| 当前状态 | 目标状态 | 触发动作 | 允许条件 |
| --- | --- | --- | --- |
| 无 | `drafting` | 创建文章 | 必须提供内容方向 |
| `drafting` | `editing` | 生成成功 | 生成出标题、正文和至少一条配图建议 |
| `drafting` | `generation_failed` | 生成失败 | 文本生成失败或关键内容缺失 |
| `generation_failed` | `drafting` | 调整配置重试 | 保留原生成配置 |
| `editing` | `pending_review` | 提交 review | 完整性校验通过 |
| `review_rejected` | `editing` | 修改退回文章 | 用户进入编辑页并保存修改 |
| `not_publish` | `editing` | 重新编辑 | 用户选择重新激活文章 |
| `pending_review` | `approved` | Review 通过 | 记录 ReviewRecord，写入 reviewedVersion |
| `pending_review` | `review_rejected` | Review 退回 | 记录退回原因 |
| `pending_review` | `not_publish` | Review 暂不发布 | 记录原因或空原因 |
| `approved` | `pending_publish` | 生成发布准备 | reviewedVersion 等于 contentVersion |
| `pending_publish` | `published` | 标记已发布 | 已生成 PublishRecord |
| `pending_publish` | `publish_failed` | 标记发布失败 | 记录失败原因 |
| `publish_failed` | `pending_publish` | 重新生成发布内容 | 未修改正文、标题、摘要和图片 |
| `publish_failed` | `editing` | 修改文章内容 | 内容版本递增，需重新 review |

状态拦截规则：

- `pending_review` 不允许进入发布准备。
- `review_rejected` 不允许进入发布准备。
- `not_publish` 不允许进入发布准备。
- `approved` 后如果内容发生修改，状态回到 `editing`，`reviewedVersion` 保留但不再匹配当前 `contentVersion`。
- `published` 默认作为终态；如需二次发布，应复制为新文章或重新打开编辑链路。

规则：

## 页面详细设计

### 内容工作台

页面目标：

- 让用户快速进入新建、编辑、review 和发布准备任务。

主要区域：

- 新建文章按钮。
- 状态概览：待编辑、待Review、待发布、发布失败。
- 最近文章列表。
- 筛选区：内容方向、状态、关键词。

主要操作：

- 新建文章：跳转生成配置页。
- 继续编辑：进入图文编辑页。
- 去 review：进入 Review 页。
- 去发布准备：进入发布准备页。

状态限制：

- `pending_review` 展示 review 操作。
- `approved` 和 `pending_publish` 展示发布准备操作。
- `not_publish` 默认只展示查看和重新编辑操作。

### 生成配置页

页面目标：

- 收集文章生成参数并发起 AI 生成。

表单字段：

- 内容方向：必填。
- 主题或关键词：必填。
- 目标读者：选填。
- 文章风格：选填。
- 篇幅要求：选填。
- 参考素材：选填。

主要操作：

- 保存草稿配置。
- 生成文章。
- 重新生成。

交互规则：

- 未选择内容方向或未填写主题时，不允许生成。
- 生成中需要展示加载状态。
- 生成失败后展示失败原因和重试入口。

### 图文编辑页

页面目标：

- 让用户在 AI 草稿基础上完成发布前编辑。

主要区域：

- 标题编辑区。
- 摘要编辑区。
- 正文编辑区。
- 图片与配图区。
- 公众号预览区。
- 操作区。

主要操作：

- 保存。
- 重新生成全文。
- 编辑配图建议。
- 替换图片。
- 提交 review。

交互规则：

- 提交 review 前进行完整性校验。
- 校验失败时展示缺失项。
- `pending_review` 状态下页面只读。
- `review_rejected` 状态展示最近一次退回原因。
- 已通过后再次编辑会提示“修改后需要重新 review”。

### Review 页

页面目标：

- 让 Review 人检查完整图文内容并做发布前决策。

主要区域：

- 文章预览。
- 图片清单。
- 内容方向和生成配置。
- 风险提示区。
- 审核检查项。
- 审核意见。
- 审核操作按钮。

主要操作：

- 通过。
- 退回修改。
- 暂不发布。
- 退回后进入编辑页。

交互规则：

- 只有 `pending_review` 状态显示审核操作。
- 退回修改时审核意见必填。
- 暂不发布时审核意见选填。
- 通过后记录当前 `contentVersion`。
- 退回后进入编辑页，保存修改时文章保持或进入 `editing`。

### 发布准备页

页面目标：

- 生成公众号可复制内容，并记录发布结果。

主要区域：

- 最终标题和摘要。
- 正文预览。
- 图片清单和配图说明。
- 公众号复制内容区。
- 发布结果操作。

主要操作：

- 生成发布内容。
- 复制标题、摘要、正文。
- 标记已发布。
- 标记发布失败。

交互规则：

- 只允许 `approved` 或 `pending_publish` 状态进入核心操作。
- 如果 `reviewedVersion != contentVersion`，提示需要重新 review。
- 标记发布失败时失败原因必填。

### 历史文章页

页面目标：

- 查询文章历史记录并进入相应处理页面。

筛选条件：

- 内容方向。
- 文章状态。
- 关键词。
- 时间范围。

列表字段：

- 标题。
- 内容方向。
- 当前状态。
- 更新时间。
- 最近 review 结果。
- 发布状态。

主要操作：

- 查看详情。
- 继续编辑。
- 进入 review。
- 进入发布准备。

## 生成策略详细设计

### 统一输出结构

内容生成服务要求模型输出结构化结果：

```json
{
  "title": "文章标题",
  "summary": "文章摘要",
  "outline": ["段落一", "段落二"],
  "body": "正文",
  "imageSuggestions": [
    {
      "description": "配图建议",
      "position": "建议位置",
      "altText": "替代文本"
    }
  ],
  "riskNote": "风险提示"
}
```

输出校验：

- `title` 不为空。
- `body` 不为空。
- `imageSuggestions` 至少一条。
- 金融方向尽量生成 `riskNote`。

### 科技互联网方向策略

生成重点：

- 行业背景。
- 技术或产品变化。
- 典型案例或趋势判断。
- 对用户、公司或行业的影响。

配图建议：

- 产品界面抽象图。
- 技术架构感插图。
- 行业趋势图。

### 金融方向策略

生成重点：

- 市场背景。
- 关键数据或逻辑。
- 风险因素。
- 非投资建议表达。

配图建议：

- 数据图表风格图片。
- 市场趋势抽象图。
- 商业分析场景图。

风险提示：

- 避免承诺收益。
- 避免直接投资建议。
- 需要提示内容仅作信息分享或观点讨论。

### 文学方向策略

生成重点：

- 主题表达。
- 文学性和可读性。
- 作者、作品或文本细节。
- 情绪和观点的平衡。

配图建议：

- 书籍、阅读、手稿、城市或自然意象。
- 避免与正文无关的装饰图。

## 发布内容导出设计

### 导出组成

发布准备模块输出以下内容：

- 公众号标题。
- 摘要。
- 正文。
- 图片清单。
- 图片插入位置。
- 配图说明。
- 风险提示或发布提醒。

### 导出格式

MVP 建议先支持两种格式：

- Markdown 复制格式：便于在系统内保存和二次编辑。
- 公众号后台复制格式：尽量保留标题层级、段落和图片占位。

图片占位格式：

```text
[图片：一张表现 AI Agent 连接多个应用的科技风插图]
```

真实图片存在时：

```text
[图片：image_001.png，建议位置：摘要后]
```

## 异常处理设计

### 生成失败

触发场景：

- 外部模型调用失败。
- 模型输出缺少标题或正文。
- 模型输出无法解析。

处理方式：

- 状态进入 `generation_failed`。
- 记录失败原因。
- 保留生成配置。
- 提供重试入口。

### 内容不完整

触发场景：

- 标题为空。
- 正文为空。
- 没有图片内容或配图方案。
- 内容方向缺失。

处理方式：

- 不改变文章状态。
- 返回缺失字段。
- 在编辑页展示补齐提示。

### 非法状态流转

触发场景：

- 未 review 文章进入发布准备。
- 暂不发布文章进入发布准备。
- 已发布文章直接编辑。

处理方式：

- 阻断操作。
- 返回当前状态和允许操作。
- 记录异常事件。

### 发布失败

触发场景：

- 用户标记人工发布失败。
- 导出内容生成失败。
- 后续公众号接口调用失败。

处理方式：

- 状态进入 `publish_failed`。
- 记录失败原因。
- 未修改内容时允许重新生成发布准备。
- 修改内容时回到 `editing` 并重新 review。

## 日志与审计设计

MVP 需要记录以下事件：

- 文章创建。
- 生成成功和失败。
- 内容保存。
- 提交 review。
- review 通过、退回、暂不发布。
- 生成发布准备。
- 标记发布成功或失败。
- 非法状态流转拦截。

日志字段：

- `eventType`
- `articleId`
- `fromStatus`
- `toStatus`
- `message`
- `createdAt`

## 安全与权限设计

MVP 采用单用户模型，但保留业务安全规则：

- 所有发布准备必须经过状态流转模块校验。
- 未通过 review 的文章不能导出发布内容。
- 暂不发布文章不能导出发布内容。
- 内容修改后必须重新 review。
- 图片来源和生成方式必须记录。

后续多人权限扩展建议：

- 创作者可创建和编辑文章。
- Review 人可审核文章。
- 发布执行者可执行发布准备和发布结果标记。
- 管理员可查看全部记录和配置生成策略。

## MVP 验收点

### 需求验收

- 输入主题和内容方向后，可以生成文章草稿。
- 内容方向支持科技互联网、金融、文学。
- 文章草稿包含标题、摘要、正文和至少一项图片内容或配图方案。
- 用户可以编辑标题、摘要、正文和图片记录。
- 用户可以提交 review。
- Review 可以通过、退回修改、暂不发布。
- 未通过 review 的文章不能进入发布准备。
- Review 通过后可以生成公众号可复制内容。

### 状态验收

- `editing` 才能提交 review。
- `pending_review` 不能发布。
- `approved` 才能进入发布准备。
- `not_publish` 不能进入发布准备。
- 内容修改后需要重新 review。
- 发布失败可以记录失败原因。

### 页面验收

- 工作台能看到待编辑、待Review、待发布文章。
- 生成配置页能创建并发起生成。
- 图文编辑页能保存内容并提交 review。
- Review 页能查看完整图文并做审核决策。
- 发布准备页能生成可复制内容并标记发布结果。
- 历史文章页能按方向和状态筛选。

## 与需求和用户动线的 Review

### 对初版需求的覆盖

- “公众号分享”：发布准备模块输出公众号可复制内容。
- “科技互联网、金融、文学”：生成配置和提示词策略均按三类方向设计。
- “内容生成”：GenerationService 负责生成标题、摘要、正文和配图建议。
- “文章推送”：MVP 以发布准备承接，后续通过外部能力适配模块对接公众号接口。
- “有文有图”：ContentValidationService 强制校验正文和图片内容或配图方案。
- “发表前介入 review”：ReviewService 和 ArticleStatusService 强制控制发布前审核。

### 对用户动线的覆盖

```text
进入创作入口
  -> 内容工作台
选择方向和主题
  -> 生成配置页
生成图文草稿
  -> GenerationService + ImageService
人工编辑
  -> 图文编辑页 + EditorService
提交 review
  -> ContentValidationService + ReviewService
审核决策
  -> Review 页 + ArticleStatusService
发布准备
  -> 发布准备页 + PublishPreparationService
历史查看
  -> 历史文章页 + ArticleService
```

### 已收敛的设计决策

- Review 页不直接编辑正文；编辑动作统一由图文编辑页承载。
- 图片初版允许以配图建议形式存在，不阻塞 MVP。
- 发布准备不等于正式发布；公众号接口后续接入。
- 金融合规初版做风险提示和人工检查，自动检测后续增强。

## 后续开发计划输入

建议将开发拆成以下阶段：

1. 数据模型、状态流转和内容完整性校验。
2. 文章创建、生成配置和图文草稿生成。
3. 图文编辑和图片配图管理。
4. Review 审核和审核记录。
5. 发布准备、导出内容和发布结果记录。
6. 工作台、历史文章和状态筛选。
7. AI 图片、素材库、公众号接口和金融合规增强。
